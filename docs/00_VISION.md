# Palimpsest — Vision

A deterministic consultation machine containing a large authored reality.
The player does not control a protagonist. They operate the machine,
inspect records, form theories, answer it, and gradually learn what kind
of object they are interacting with.

The machine is the persistent character. It has no name in-fiction.

## Non-negotiables

- No runtime LLM. No server. Everything the player reads was authored
  and frozen before ship. AI is a build-time tool only (drafting,
  combinatorial testing, simulating how players will misread things).
- The player is never asked "what do you do." The machine asks
  questions; the player answers it, or it makes observations and waits.
- Text never silently rewrites. The same sentence can change *epistemic
  status* (see 01) without changing a single word.
- Confusion must periodically resolve into something verifiable. Reward
  correct theories with evidence, not achievements.
- Accessibility is shipped in the MVP, not retrofitted (see 01, Legend).

## What the player is actually doing

Reconstructing an object that can never be displayed directly, from
fragments recorded across many sessions, using a machine whose own
limitations and wear are part of the evidence.
